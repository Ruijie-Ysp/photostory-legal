快速排查

App 打不开照片 / 一片空白

  1. 系统设置 → 此地 → 照片，确认是「完全访问」或至少选中了需要的照片；
  2. 若开了「优化 iPhone 存储」，iCloud 照片需要先下载到本机；
  3. 仍不行：强制退出 App 后重开，或在设置里切换一次权限。

AI 功能按钮是灰的 / 提示配置模型

  • 此地不自带在线服务。你可以：
    1. 在「设置 → AI 模型与服务」里配置一个兼容 OpenAI API 的服务（自带 API Key）；或
    2. 在「模型库与下载」里下载端侧模型（需要 6–16 GB 内存，模型 1–6 GB）。
  • 端侧模型完全离线；在线模型按隐私政策发送压缩画面与事实文字。

为什么下载模型这么大？会占多少空间？

  • 端侧模型用于离线配文/讲解，体积 1–6 GB，可在「模型库与下载」删除；
  • 地图/地形瓦片按需下载，可随时清除；
  • 清理扫描的缓存只有几百 KB。

清理建议会不会误删？

  • 不会自动删。必须你勾选 → 点「删除所选」→ 本页确认 → 系统再确认；
  • 删除的照片进系统「最近删除」，默认保留 30 天，可在系统相册恢复；
  • 判据是清晰度、高光溢出、系统截图标记、视频时长、相似度；拿不到画面信号的项目不会被标记。

照片/记录会上传吗？

  • 默认不会。只有你主动配置并使用在线模型时，才会把压缩画面或文字发给你指定的服务；
  • 我们没有服务器，也不收集账号或分析数据。详见隐私政策。

换手机/重装 App，数据还在吗？

  • 当前版本没有账号与云同步。照片仍在系统相册；App 内的行程、配文、探索记录保存在本机，卸载后删除。重装后需要重新授权与重新建立索引。

购买与退款

  • 如未来提供付费功能，将通过 App Store 内购完成；退款请走 Apple 的退款流程（reportaproblem.apple.com），开发者无法代退款。

发现地点/山名/海拔不对

  • 照片详情底部有「发现地点或山名有误？」入口，提交后会记录在本机并优先采用你的修正；当前版本不会自动上传纠错。

反馈问题时请附上

  1. 机型与系统版本（例如 iPhone 16 Pro / iOS 27.0.1）；
  2. App 版本（设置页底部）；
  3. 复现步骤与截图；
  4. 如果是 AI 问题：用的是端侧还是在线服务（不要发送 API Key）。
